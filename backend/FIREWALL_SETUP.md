# AWS Lightsail 방화벽 설정 가이드

## 새 인스턴스 IP
- **43.201.148.223**

## 필요한 방화벽 규칙

### 현재 열려있는 포트
- ✅ **22 (SSH)**: SSH 접속용
- ✅ **80 (HTTP)**: HTTP 접속용

### 추가로 필요한 포트

#### 1. HTTPS (443) - 필수
- **애플리케이션**: Custom
- **프로토콜**: TCP
- **포트**: 443
- **제한**: 모든 IPv4 주소

#### 2. Node.js 백엔드 (3000) - 선택사항
- **애플리케이션**: Custom
- **프로토콜**: TCP
- **포트**: 3000
- **제한**: 모든 IPv4 주소
- **참고**: Nginx 리버스 프록시를 사용하면 직접 노출할 필요 없음

#### 3. MySQL (3306) - 선택사항 (보안상 비추천)
- **애플리케이션**: MySQL
- **프로토콜**: TCP
- **포트**: 3306
- **제한**: 특정 IP 주소만 (가능하면 열지 않음)
- **참고**: 외부에서 직접 접속할 필요가 없으면 열지 마세요

## 방화벽 규칙 추가 방법

### 1단계: HTTPS (443) 포트 추가

1. Lightsail 콘솔에서 인스턴스 선택
2. **"네트워킹"** 탭 클릭
3. **"IPv4 방화벽"** 섹션에서 **"+ 규칙 추가"** 클릭
4. 다음 정보 입력:
   - **애플리케이션**: Custom
   - **프로토콜**: TCP
   - **포트 또는 범위**: 443
   - **제한**: 모든 IPv4 주소
5. **"저장"** 클릭

### 2단계: (선택) Node.js 포트 추가

Nginx를 사용하지 않고 직접 접속하려면:

1. **"+ 규칙 추가"** 클릭
2. 다음 정보 입력:
   - **애플리케이션**: Custom
   - **프로토콜**: TCP
   - **포트 또는 범위**: 3000
   - **제한**: 모든 IPv4 주소
3. **"저장"** 클릭

## 권장 설정

### 최소 설정 (Nginx 사용 시)
- ✅ SSH (22)
- ✅ HTTP (80)
- ✅ HTTPS (443)

### 추가 설정 (직접 접속 필요 시)
- ✅ Node.js (3000) - Nginx 없이 직접 접속할 때만

## 보안 권장사항

1. **MySQL 포트는 열지 마세요**: 외부에서 직접 접속할 필요 없음
2. **특정 IP만 허용**: 가능하면 특정 IP 주소만 허용하도록 제한
3. **불필요한 포트는 닫기**: 사용하지 않는 포트는 열지 않음

## 설정 후 확인

방화벽 규칙 추가 후:

```bash
# 서버에 SSH 접속
ssh -i C:\KKJ\LightsailDefaultKey-ap-northeast-2.pem ubuntu@43.201.148.223

# 포트 리스닝 확인
sudo netstat -tlnp | grep -E '3000|443|80'

# 또는
sudo ss -tlnp | grep -E '3000|443|80'
```

## Nginx 설정 확인

HTTPS가 제대로 작동하는지 확인:

```bash
# Nginx 상태 확인
sudo systemctl status nginx

# Nginx 설정 확인
sudo nginx -t

# SSL 인증서 확인
sudo certbot certificates
```

## 문제 해결

### 포트가 열려있는데 접속이 안 될 때

1. **방화벽 규칙 확인**: Lightsail 콘솔에서 규칙이 제대로 추가되었는지 확인
2. **서버 내부 방화벽 확인**:
   ```bash
   sudo ufw status
   sudo ufw allow 443/tcp
   ```
3. **애플리케이션 실행 확인**:
   ```bash
   pm2 status
   pm2 logs ces-smartfarm
   ```
