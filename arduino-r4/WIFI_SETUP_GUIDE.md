# WiFi 웹 설정 가이드

## 개요

하드코딩된 WiFi 정보 대신, **WiFi AP 모드**를 통해 웹 브라우저로 WiFi 설정을 할 수 있습니다.

## 작동 방식

1. **첫 부팅 시**: WiFi 설정이 없으면 자동으로 AP 모드로 시작
2. **웹 설정 페이지**: 스마트폰/컴퓨터로 접속하여 WiFi 정보 입력
3. **EEPROM 저장**: 설정한 WiFi 정보를 EEPROM에 저장
4. **자동 연결**: 다음 부팅부터 저장된 WiFi에 자동 연결

## 사용 방법

### 1단계: 아두이노 업로드
- `wifi_config.h`와 수정된 `main.ino`를 포함하여 업로드

### 2단계: WiFi AP 모드 확인
- 시리얼 모니터에서 다음 메시지 확인:
  ```
  WiFi 설정이 없습니다. 설정 포털을 시작합니다.
  Starting WiFi Configuration Portal...
  AP IP address: 192.168.4.1
  Connect to WiFi: CES_SmartFarm_Setup
  Then open browser: http://192.168.4.1
  ```

### 3단계: 스마트폰/컴퓨터로 연결
1. **WiFi 목록에서 "CES_SmartFarm_Setup" 찾기**
2. **연결** (비밀번호 없음)
3. **웹 브라우저 열기**: `http://192.168.4.1`

### 4단계: WiFi 정보 입력
- 웹 페이지에서:
  - WiFi 이름 (SSID) 입력
  - WiFi 비밀번호 입력
  - "설정 저장" 버튼 클릭

### 5단계: 완료
- "설정이 저장되었습니다!" 메시지 확인
- 아두이노가 자동으로 재시작되며 저장된 WiFi에 연결

## 설정 초기화

설정을 초기화하려면:
- 시리얼 모니터에서 `RESET` 명령 전송
- 또는 EEPROM을 지우는 코드 추가

## 장점

✅ 하드코딩 불필요
✅ 여러 환경에서 사용 가능
✅ 비밀번호 보안 (코드에 노출 안 됨)
✅ 사용자 친화적 웹 인터페이스

## 주의사항

- 첫 부팅 시에만 AP 모드로 시작
- WiFi 연결 후에는 정상 모드로 작동
- EEPROM에 저장되므로 전원이 꺼져도 유지됨
