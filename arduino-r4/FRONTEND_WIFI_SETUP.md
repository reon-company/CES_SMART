# 프론트엔드에서 WiFi 설정하기

## 개요

이제 **프론트엔드 웹 대시보드에서 모듈 추가 시 WiFi 정보를 함께 설정**할 수 있습니다!

## 사용 방법

### 1단계: 웹 대시보드에서 모듈 추가

1. **로그인 후 대시보드 접속**

   - http://localhost:3001/dashboard/modules

2. **"모듈 추가" 버튼 클릭**

3. **모듈 정보 입력:**

   - **모듈 이름**: 예) "수조 1호"
   - **모듈 ID**: 예) "MODULE_001" (아두이노에서 설정한 ID)
   - **WiFi 이름 (SSID)**: 연결할 WiFi 이름
   - **WiFi 비밀번호**: WiFi 비밀번호

4. **"추가" 버튼 클릭**

### 2단계: 아두이노 설정

#### 방법 1: 서버에서 자동으로 WiFi 정보 받기 (권장)

1. **임시 WiFi 연결** (모바일 핫스팟 등)

   - 아두이노가 서버에 접속할 수 있도록 임시 WiFi에 연결
   - 또는 이미 다른 WiFi에 연결되어 있어야 함

2. **아두이노 업로드 및 실행**

   - 아두이노가 자동으로 서버에서 WiFi 정보를 받아서 연결

3. **연결 확인**
   - 시리얼 모니터에서 "서버 WiFi로 연결 성공!" 메시지 확인

#### 방법 2: 웹 설정 페이지 사용 (대안)

- 서버에서 WiFi 정보를 받을 수 없을 때
- 아두이노가 AP 모드로 시작
- 웹 브라우저에서 `http://192.168.4.1` 접속하여 설정

## 작동 원리

1. **프론트엔드**: 모듈 추가 시 WiFi 정보를 백엔드에 저장
2. **백엔드**: 데이터베이스에 WiFi 정보 저장
3. **아두이노**: 서버에서 WiFi 정보를 받아서 연결
4. **EEPROM**: 연결 성공 후 WiFi 정보를 EEPROM에 저장 (다음 부팅 시 자동 연결)

## 장점

✅ **중앙 관리**: 모든 모듈의 WiFi 정보를 웹 대시보드에서 관리
✅ **편리함**: 코드 수정 없이 웹에서 설정 변경 가능
✅ **보안**: WiFi 비밀번호가 코드에 하드코딩되지 않음
✅ **다중 모듈**: 여러 모듈을 쉽게 관리

## 데이터베이스 변경사항

`modules` 테이블에 다음 컬럼이 추가되었습니다:

- `wifi_ssid`: WiFi 이름
- `wifi_password`: WiFi 비밀번호

## API 엔드포인트

### WiFi 설정 가져오기 (아두이노용)

```
GET /api/modules/:moduleId/wifi-config
```

응답:

```json
{
  "success": true,
  "wifi_ssid": "SK_WiFiGIGA91A3_2.4G",
  "wifi_password": "2006076422"
}
```

## 주의사항

- **첫 부팅 시**: 아두이노가 서버에 접속하려면 임시 WiFi에 연결되어 있어야 함
- **보안**: WiFi 비밀번호가 평문으로 전송되므로 HTTPS 사용 권장
- **모듈 ID**: 아두이노의 `MODULE_ID`와 웹에서 입력한 모듈 ID가 일치해야 함

## 문제 해결

### 서버에서 WiFi 정보를 받을 수 없음

→ 임시 WiFi(핫스팟)에 연결 후 다시 시도

### 모듈 ID 불일치

→ 아두이노의 `MODULE_ID`와 웹에서 입력한 모듈 ID 확인

### WiFi 연결 실패

→ WiFi SSID와 비밀번호 확인, 2.4GHz 대역인지 확인
