# 시리얼 모니터 문제 해결 가이드

## 시리얼 모니터가 동작하지 않을 때

### 1단계: 기본 확인

#### 포트 선택 확인
1. **Tools > Port** 메뉴 확인
2. 아두이노가 연결된 포트 선택
   - Windows: `COM3`, `COM4` 등
   - Mac: `/dev/cu.usbmodem...` 또는 `/dev/tty.usbmodem...`
   - Linux: `/dev/ttyACM0`, `/dev/ttyUSB0` 등
3. 포트가 목록에 없으면:
   - USB 케이블 재연결
   - Arduino IDE 재시작

#### 보드레이트 확인
1. **Tools > Serial Monitor** 열기
2. 우측 하단에서 **보드레이트 선택**
3. **9600** 또는 **115200** 선택 (코드의 `Serial.begin()` 값과 일치해야 함)
4. 코드 확인:
   ```cpp
   Serial.begin(9600);  // 또는 115200
   ```

### 2단계: 시리얼 모니터 설정 확인

#### Arduino IDE 설정
1. **Tools > Serial Monitor** (`Ctrl+Shift+M` / `Cmd+Shift+M`)
2. 보드레이트가 코드와 일치하는지 확인
3. **"Both NL & CR"** 또는 **"No line ending"** 선택

#### 여러 시리얼 모니터 창
- 시리얼 모니터는 한 번에 하나만 열 수 있습니다
- 다른 프로그램(예: PuTTY, Tera Term)이 포트를 사용 중일 수 있음
- 모든 시리얼 모니터/터미널 프로그램 종료 후 다시 시도

### 3단계: 하드웨어 확인

#### USB 케이블
- **데이터 전송 가능한 USB 케이블** 사용 (충전 전용 케이블 아님)
- USB 케이블을 다른 포트에 연결해보기
- 다른 USB 케이블로 교체해보기

#### 아두이노 전원
- 아두이노의 전원 LED가 켜져있는지 확인
- USB 포트가 전원을 공급하는지 확인

### 4단계: 드라이버 확인 (Windows)

#### 장치 관리자 확인
1. **Win + X** → **장치 관리자**
2. **포트 (COM & LPT)** 확장
3. Arduino R4 WiFi 확인:
   - 노란색 경고 표시가 있으면 드라이버 문제
   - 드라이버 업데이트 필요

#### 드라이버 설치
1. Arduino IDE 설치 시 드라이버가 자동 설치됨
2. 수동 설치가 필요한 경우:
   - Arduino 공식 웹사이트에서 드라이버 다운로드
   - 또는 Arduino IDE 재설치

### 5단계: 코드 확인

#### Serial.begin() 확인
코드에 다음이 있는지 확인:
```cpp
void setup() {
  Serial.begin(9600);  // 또는 115200
  // ...
}
```

#### 보드레이트 일치
- 코드: `Serial.begin(9600)` → 시리얼 모니터: **9600**
- 코드: `Serial.begin(115200)` → 시리얼 모니터: **115200**

### 6단계: Arduino IDE 재시작

1. Arduino IDE 완전 종료
2. 다시 실행
3. 포트 다시 선택
4. 시리얼 모니터 다시 열기

### 7단계: 아두이노 재부팅

1. **RESET 버튼** 누르기
2. 또는 USB 케이블 뽑았다가 다시 연결
3. 시리얼 모니터에서 부팅 메시지 확인

## 일반적인 보드레이트

- **9600**: 일반적인 속도 (권장)
- **115200**: 빠른 속도 (디버깅용)

## 시리얼 모니터가 여전히 작동하지 않으면

1. **다른 시리얼 모니터 프로그램 사용**:
   - Windows: PuTTY, Tera Term
   - Mac/Linux: `screen /dev/tty.usbmodem* 9600` 또는 `minicom`

2. **Arduino IDE 재설치**

3. **다른 컴퓨터에서 테스트**

## 정상 작동 시 예상 출력

시리얼 모니터가 정상 작동하면 다음과 같은 메시지가 보여야 합니다:

```
SETUP_START
========================================
CES SmartFarm Arduino R4 Starting
========================================
Module ID: MODULE_001
...
```

## 문제 해결 후

시리얼 모니터가 작동하면:
1. 서버 연결 디버그 정보 확인
2. "Connection to server failed!" 원인 파악
3. Lightsail 방화벽에서 포트 3000 열기
