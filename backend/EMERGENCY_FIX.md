# 서버 접속 불가 긴급 해결 가이드

## 현재 상황
- SSH 접속 불가 (로컬 및 브라우저 모두)
- HTTP API는 매우 느리게 응답
- 서버가 심각한 상태로 보임

## 즉시 조치 사항

### 1. AWS Lightsail 콘솔에서 인스턴스 상태 확인

1. **AWS Lightsail 콘솔 접속**
   - https://lightsail.aws.amazon.com/
   - 로그인

2. **인스턴스 상태 확인**
   - 인스턴스 목록에서 상태 확인:
     - 🟢 "실행 중" (Running)
     - 🔴 "중지됨" (Stopped)
     - 🟡 "재시작 중" (Rebooting)
     - 🟠 "시작 중" (Starting)

3. **Metrics 확인**
   - 인스턴스 클릭
   - "Metrics" 탭 확인:
     - CPU 사용률
     - 메모리 사용률
     - 네트워크 인바운드/아웃바운드

### 2. 인스턴스 재시작 (가장 빠른 해결책)

**옵션 A: 재부팅 (Reboot)**
- 인스턴스 선택
- "Actions" → "Reboot"
- 1-2분 대기

**옵션 B: 중지 후 시작 (Stop & Start)**
- 인스턴스 선택
- "Actions" → "Stop"
- 완전히 중지될 때까지 대기 (1-2분)
- "Actions" → "Start"
- 시작될 때까지 대기 (1-2분)

⚠️ **주의**: Stop & Start를 하면 **IP 주소가 변경될 수 있습니다!**

### 3. 인스턴스 사양 확인

1. **인스턴스 타입 확인**
   - 인스턴스 선택
   - "Account and resources" 또는 "Settings" 탭
   - 현재 인스턴스 타입 확인 (예: $3.50 USD/mo - 512 MB RAM)

2. **리소스 부족 가능성**
   - nano/micro 인스턴스는 리소스가 매우 제한적
   - CPU 100% 또는 메모리 부족으로 인해 응답 불가능할 수 있음

### 4. 인스턴스 스냅샷 생성 (데이터 백업)

재시작 전에 데이터 백업:

1. 인스턴스 선택
2. "Snapshots" 탭
3. "Create snapshot" 클릭
4. 스냅샷 이름 입력
5. 생성 완료 대기

### 5. 새 인스턴스 생성 (최후의 수단)

현재 인스턴스가 계속 문제가 있다면:

1. **스냅샷 생성** (위 단계)
2. **새 인스턴스 생성**
   - "Create instance" 클릭
   - "Launch from snapshot" 선택
   - 방금 생성한 스냅샷 선택
   - 더 큰 인스턴스 타입 선택 (권장)
3. **새 IP 주소 확인**
4. **프론트엔드 API URL 업데이트**

## 단계별 해결 순서

### 즉시 시도 (5분 이내)

1. ✅ **AWS Lightsail 콘솔 접속**
2. ✅ **인스턴스 상태 확인**
3. ✅ **Metrics 확인** (CPU, 메모리)
4. ✅ **인스턴스 재부팅** (Reboot)

### 재부팅 후 (5-10분)

1. ✅ **새 IP 주소 확인** (변경되었을 수 있음)
2. ✅ **SSH 연결 테스트**
3. ✅ **HTTP API 테스트**
4. ✅ **프론트엔드 API URL 업데이트** (IP 변경 시)

### 문제가 지속되는 경우

1. ✅ **스냅샷 생성**
2. ✅ **인스턴스 사양 업그레이드 고려**
3. ✅ **새 인스턴스 생성** (스냅샷에서)

## 예상 결과

### 재부팅 후 정상인 경우
- SSH 접속 가능
- HTTP API 빠른 응답
- IP 주소는 동일하거나 변경됨

### 재부팅 후에도 문제가 있는 경우
- 인스턴스 사양 부족 가능성
- 인스턴스 업그레이드 또는 새 인스턴스 생성 필요

## IP 주소 변경 시 업데이트 필요

인스턴스를 Stop & Start하면 IP가 변경될 수 있습니다.

### 업데이트할 파일

1. **frontend/public/js/api.js**
   ```javascript
   return 'https://새로운_IP_주소';
   ```

2. **DNS 레코드** (Route 53)
   - A 레코드 값 업데이트: `54.180.237.225` → `새로운_IP_주소`

3. **Nginx 설정** (서버 내부)
   - SSL 인증서 재발급 필요 (IP 변경 시)
