========================================
시리얼 모니터 빠른 해결 방법
========================================

[1] 포트 확인
------------------
Tools > Port > (아두이노 포트 선택)
- Windows: COM3, COM4 등
- 포트가 안 보이면 USB 케이블 재연결

[2] 보드레이트 확인
------------------
Tools > Serial Monitor 열기
우측 하단에서 보드레이트 선택:
- 9600 (일반)
- 115200 (빠름)

코드의 Serial.begin() 값과 일치해야 함!

[3] 다른 프로그램 종료
------------------
- PuTTY, Tera Term 등 시리얼 프로그램 종료
- 시리얼 모니터는 한 번에 하나만 사용 가능

[4] Arduino IDE 재시작
------------------
- 완전 종료 후 다시 실행
- 포트 다시 선택

[5] 아두이노 재부팅
------------------
- RESET 버튼 누르기
- 또는 USB 케이블 뽑았다가 다시 연결

[6] USB 케이블 확인
------------------
- 데이터 전송 가능한 케이블 사용
- 충전 전용 케이블은 작동 안 함

========================================
체크리스트
========================================
□ 포트 선택됨
□ 보드레이트 일치 (9600 또는 115200)
□ 다른 시리얼 프로그램 종료
□ Arduino IDE 재시작
□ 아두이노 재부팅
□ USB 케이블 확인

========================================
여전히 안 되면
========================================
1. 다른 컴퓨터에서 테스트
2. Arduino IDE 재설치
3. 다른 시리얼 모니터 프로그램 사용
   - Windows: PuTTY
   - Mac/Linux: screen 명령어
