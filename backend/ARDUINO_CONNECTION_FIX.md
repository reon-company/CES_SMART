# 아두이노 서버 연결 문제 해결

## 문제 상황
- ✅ WiFi 연결 성공 (IP: 192.168.1.12)
- ✅ MODULE_ID: MODULE_001
- ✅ API_BASE_URL: http://43.201.148.223:3000
- ❌ "Connection to server failed!" 반복 발생

## 원인 분석

### 확인된 사항
1. **서버 상태**: 정상 작동 중 (포트 3000 리스닝)
2. **서버 로그**: MODULE_001에 대한 액추에이터 요청은 있지만 센서 데이터 POST 요청 없음
3. **가능한 원인**: 
   - Lightsail 방화벽에서 포트 3000이 닫혀있을 수 있음
   - 아두이노 네트워크에서 외부 IP 접속이 차단될 수 있음

## 해결 방법

### 방법 1: Lightsail 방화벽에서 포트 3000 열기 (권장)

1. AWS Lightsail 콘솔 접속
2. 인스턴스 선택 → "네트워킹" 탭
3. "+ 규칙 추가" 클릭
4. 설정:
   - **애플리케이션**: Custom
   - **프로토콜**: TCP
   - **포트 또는 범위**: 3000
   - **제한**: 모든 IPv4 주소
5. 저장

### 방법 2: Nginx를 통해 접속 (대안)

아두이노가 포트 80(HTTP)을 통해 접속하도록 변경:

```cpp
// config.h
#define API_BASE_URL "http://43.201.148.223"  // 포트 80 사용
```

그리고 Nginx 설정에서 `/api` 경로를 백엔드로 프록시하도록 설정 (이미 되어있을 수 있음).

### 방법 3: 디버그 정보 확인

아두이노 코드에 디버그 출력을 추가했습니다. 시리얼 모니터에서 다음 정보를 확인하세요:

```
API Base URL: http://43.201.148.223:3000
Parsed Host: 43.201.148.223
Parsed Port: 3000
Attempting to connect to: 43.201.148.223:3000
```

이 정보로 실제 연결 시도하는 호스트와 포트를 확인할 수 있습니다.

## 확인 단계

### 1. 방화벽 확인
Lightsail 콘솔에서 포트 3000이 열려있는지 확인

### 2. 서버 접속 테스트
다른 컴퓨터/스마트폰에서:
```bash
curl http://43.201.148.223:3000/api/health
```

### 3. 아두이노 네트워크 확인
아두이노가 연결된 네트워크(192.168.1.x)에서:
- 인터넷 연결 확인
- 외부 IP 접속 가능 여부 확인

## 빠른 해결

**가장 빠른 해결책**: Lightsail 방화벽에서 포트 3000을 열어주세요.

포트를 열면 아두이노가 바로 서버에 연결할 수 있습니다.
