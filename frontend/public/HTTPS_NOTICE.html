HTTPS 설정 필요

백엔드 서버에 HTTPS 설정이 필요합니다

문제 상황

SSL 인증서 오류(ERR_CERT_AUTHORITY_INVALID)가 발생했습니다. 자체 서명 인증서를 사용하고 있어 브라우저가 신뢰하지 않습니다.

해결 방법

브라우저에서 인증서를 수동으로 허용해야 합니다.

방법 1: 브라우저 주소창에서 허용

  1. 브라우저 주소창의 자물쇠 아이콘 클릭
  2. "인증서가 유효하지 않음" 또는 "연결이 비공개로 설정되어 있지 않음" 클릭
  3. "고급" 또는 "Advanced" 클릭
  4. "54.180.237.225(으)로 이동" 또는 "Proceed to 54.180.237.225" 클릭

방법 2: 직접 API 주소 접속

다음 주소로 직접 접속하여 인증서 허용:

https://54.180.237.225/api/health

서버에서 실행할 명령어:

# 1. Nginx 설치
sudo apt update
sudo apt install nginx -y

# 2. 자체 서명 인증서 생성
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/ssl/private/ces-api.key \
  -out /etc/ssl/certs/ces-api.crt \
  -subj "/C=KR/ST=Seoul/L=Seoul/O=CES/CN=54.180.237.225"

# 3. Nginx 설정 파일 생성
sudo nano /etc/nginx/sites-available/ces-api

Nginx 설정 내용

server {
    listen 80;
    server_name 54.180.237.225;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name 54.180.237.225;

    ssl_certificate /etc/ssl/certs/ces-api.crt;
    ssl_certificate_key /etc/ssl/private/ces-api.key;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
