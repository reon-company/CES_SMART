문서센터 개요

이 문서센터는 납품 이후 신규 담당자가 문서만 보고도 개발/서버/현장 운영을 재현할 수 있도록 구성한 인수인계 허브입니다. 첫 사용자는 아래 권장 시작 경로를 따라가고, 숙련 사용자는 문서 검색과 카테고리 목록으로 필요한 문서에 바로 접근하세요.

장애 대응

처음 사용자 시작 경로 (권장 순서)

1단계: 전체 구조 이해

납품 통합 가이드로 시스템 전체 구조와 용어를 먼저 파악

2단계: 개발 환경 재현

개발 이관 체크리스트 기준으로 로컬에서 기능 재현

3단계: 서버 이관 검증

배포/DB/PM2/Nginx/Tailscale 경로를 순서대로 점검

4단계: 유지보수 규약 숙지

변경 전 주석 규약/영향도/롤백 정책 확인

역할별 권장 문서

프론트/백엔드 개발 담당

`납품 통합 가이드 → backend/frontend 핸드오버 → 개발 이관 체크리스트 → 주석 규약` 순서 추천

서버/인프라 운영 담당

`납품 통합 가이드 → 서버 이관 체크리스트 → backend 핸드오버` 순서 추천

현장 하드웨어 담당

`arduino/esp32 핸드오버 → 서버 이관 체크리스트의 카메라 네트워크 섹션` 순서 추천
