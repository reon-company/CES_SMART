# 시리얼 모니터 문제 해결

## 시리얼 모니터에 메시지가 안 나올 때

### 1. 시리얼 모니터 설정 확인

**아두이노 IDE에서:**
1. **Tools > Serial Monitor** 열기
2. **보드레이트 확인**: 오른쪽 하단에서 **9600** 선택
3. **줄바꿈 확인**: "Both NL & CR" 또는 "Newline" 선택

### 2. 포트 확인

**Tools > Port** 에서:
- 아두이노가 연결된 포트가 선택되어 있는지 확인
- 포트가 보이지 않으면 USB 케이블 확인

### 3. 아두이노 재시작

1. **아두이노 보드의 RESET 버튼 누르기**
2. 또는 **USB 케이블을 뽑았다가 다시 꽂기**
3. 시리얼 모니터를 닫았다가 다시 열기

### 4. 코드 확인

`setup()` 함수에서 `Serial.begin(9600)`이 호출되는지 확인:
```cpp
void setup() {
  Serial.begin(9600);
  delay(1000);  // 시리얼 포트 초기화 대기
  Serial.println("=== CES SmartFarm Arduino R4 Starting ===");
  // ...
}
```

### 5. 하드웨어 확인

- USB 케이블이 데이터 전송 가능한 케이블인지 확인 (충전 전용 케이블 아님)
- 아두이노 보드의 전원 LED가 켜져 있는지 확인
- 다른 USB 포트에 연결해보기

### 6. 아두이노 IDE 재시작

- 아두이노 IDE를 완전히 종료하고 다시 시작
- 시리얼 모니터를 닫고 다시 열기

### 7. 간단한 테스트 코드 업로드

문제가 계속되면 간단한 테스트 코드로 확인:

```cpp
void setup() {
  Serial.begin(9600);
  delay(2000);
  Serial.println("Hello from Arduino!");
}

void loop() {
  Serial.println("Loop running...");
  delay(1000);
}
```

이 코드가 작동하면 원래 코드에 문제가 있을 수 있습니다.

### 8. 보드 선택 확인

**Tools > Board** 에서:
- **Arduino UNO R4 WiFi** 선택되어 있는지 확인

## 일반적인 원인

1. **보드레이트 불일치**: 코드는 9600인데 모니터는 다른 속도
2. **포트 미선택**: 포트가 선택되지 않음
3. **시리얼 포트 점유**: 다른 프로그램이 포트를 사용 중
4. **하드웨어 문제**: USB 케이블이나 포트 문제

## 빠른 체크리스트

- [ ] Tools > Port에서 포트 선택됨
- [ ] Tools > Board에서 "Arduino UNO R4 WiFi" 선택됨
- [ ] Serial Monitor 보드레이트: 9600
- [ ] 아두이노 RESET 버튼 눌러봄
- [ ] 시리얼 모니터를 닫았다가 다시 열어봄
- [ ] USB 케이블이 데이터 전송 가능한 케이블인지 확인
