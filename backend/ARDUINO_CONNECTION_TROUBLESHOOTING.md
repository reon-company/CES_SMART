# 아두이노 서버 연결 문제 해결 가이드

## 현재 상황
- ✅ WiFi 연결 성공 (IP: 192.168.1.12)
- ✅ MODULE_ID: MODULE_001
- ✅ API_BASE_URL: http://43.201.148.223:3000
- ❌ "Connection to server failed!" 반복 발생

## 서버 상태 확인

서버는 정상 작동 중입니다:
- ✅ 포트 3000 리스닝 중
- ✅ 서버에서 직접 접속 테스트 성공
- ✅ Node.js 서버 실행 중

## 문제 원인

아두이노가 외부 IP(43.201.148.223)에 접속할 수 없는 이유:

### 가능한 원인
1. **Lightsail 방화벽**: 포트 3000이 외부에서 접근 불가
2. **아두이노 네트워크**: 공유기/라우터가 외부 접속 차단
3. **네트워크 정책**: 아두이노 네트워크에서 외부 IP 접속 제한

## 해결 방법

### 방법 1: Lightsail 방화벽에서 포트 3000 열기 (가장 중요!)

1. **AWS Lightsail 콘솔** 접속
2. 인스턴스 선택 → **"네트워킹"** 탭
3. **"+ 규칙 추가"** 클릭
4. 설정:
   - **애플리케이션**: Custom
   - **프로토콜**: TCP
   - **포트 또는 범위**: 3000
   - **제한**: 모든 IPv4 주소
5. **저장**

**이것이 가장 중요한 단계입니다!** 포트 3000이 닫혀있으면 아두이노가 서버에 접속할 수 없습니다.

### 방법 2: 디버그 정보 확인

아두이노 코드에 디버그 출력을 추가했습니다. 코드를 다시 업로드하면 시리얼 모니터에서 다음 정보를 확인할 수 있습니다:

```
API Base URL: http://43.201.148.223:3000
Parsed Host: 43.201.148.223
Parsed Port: 3000
[SENSOR] Attempting to connect to: 43.201.148.223:3000
Host: 43.201.148.223
Port: 3000
WiFi Status: 3
```

이 정보로 실제 연결 시도하는 호스트와 포트를 확인할 수 있습니다.

### 방법 3: 네트워크 테스트

아두이노가 연결된 네트워크(192.168.1.x)에서:
1. 다른 기기(PC/스마트폰)로 인터넷 연결 확인
2. `curl http://43.201.148.223:3000/api/health` 테스트
3. 접속이 안 되면 공유기/라우터 설정 확인

## 확인 체크리스트

- [ ] Lightsail 방화벽에서 포트 3000 열기
- [ ] 아두이노 코드 재업로드 (디버그 정보 포함)
- [ ] 시리얼 모니터에서 연결 정보 확인
- [ ] 서버 로그에서 센서 데이터 수신 확인

## 예상 결과

포트 3000을 열고 아두이노를 재시작하면:

```
[SENSOR] Attempting to connect to: 43.201.148.223:3000
[SENSOR] Connected to server!
Sensor data sent successfully
```

이런 메시지가 나타나야 합니다.
