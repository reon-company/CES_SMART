# SSL 인증서 오류 해결 방법

## 오류 메시지
`ERR_CERT_AUTHORITY_INVALID` - 자체 서명 인증서로 인한 오류

## 해결 방법

### 방법 1: 브라우저에서 인증서 허용 (권장)

1. **Chrome/Edge**:
   - 주소창의 자물쇠 아이콘 클릭
   - "연결이 비공개로 설정되어 있지 않음" 클릭
   - "고급" 클릭
   - "54.180.237.225(으)로 이동" 클릭

2. **Firefox**:
   - 주소창의 자물쇠 아이콘 클릭
   - "고급" 클릭
   - "위험을 감수하고 계속하기" 클릭

3. **Safari**:
   - "이 웹사이트의 인증서를 신뢰할 수 없습니다" 메시지에서
   - "계속" 클릭

### 방법 2: 직접 API 주소 접속

브라우저에서 다음 주소로 직접 접속:
```
https://54.180.237.225/api/health
```

인증서 경고에서 "고급" → "계속 진행" 클릭

### 방법 3: 브라우저 설정에서 예외 추가

**Chrome**:
1. 설정 → 개인정보 및 보안 → 보안
2. "안전하지 않은 사이트" 관리
3. 예외 추가: `https://54.180.237.225`

## 영구적 해결책

프로덕션 환경에서는 Let's Encrypt 인증서 사용 권장:

1. 도메인 필요 (예: api.ces-smart.com)
2. DNS A 레코드 설정
3. Let's Encrypt 인증서 발급

## 참고

- 자체 서명 인증서는 개발/테스트용입니다
- 프로덕션에서는 신뢰할 수 있는 인증서 사용 권장
- 현재 설정으로도 기능은 정상 작동합니다 (인증서 허용 후)
